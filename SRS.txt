Software Requirements Specification for Argus Transaction Monitor (Simplified)

3.1 Connecting to the Outside World

3.1.1 User Screens (User Interfaces)
The Argus system is a website that you can open in any browser like Chrome or Edge. It is designed for two types of people:
1. Admin: The "Boss" user. They can do everything, like checking alerts, changing rules, and fixing problems.
2. Read-only User: The "Viewer" user. They can look at the charts and logs but cannot touch or change anything.

Main Dashboard (The Control Center):
* How it looks: It has a cool dark mode so it doesn't hurt your eyes when you look at it for a long time.
* What you see:
    * Sidebar: Buttons to go to different pages like Alerts or Settings.
    * Scorecards: Big numbers showing "Total Money Transfers" or "Fake Transfers Spotted".
    * Live Charts: Graphs that move in real-time showing money coming in.
    * Recent Alerts: A list of the latest suspicious items that need checking.
* How to use it: You just use your mouse to click and your keyboard to type, like any normal website.

3.1.2 Hardware (Computer Parts)
You don't need any special machines, just normal computers.
* Server (The Brain): The main program runs on a powerful computer in the cloud (like Amazon AWS). It needs enough power to run the AI programs.
* Client (User's Computer): You can use any laptop or desktop PC to open the website.
* Internet: You need fast internet because transaction data comes in very quickly.

3.1.3 Software (Connecting to other Apps)
Argus talks to other software to do its job:
* Money Data: It connects to the bank's system to receive details about money transfers.
* Database: It uses a system called PostgreSQL to save all the records safely, like a digital filing cabinet.
* Message Broker: It uses a tool called Redis to organize tasks, like a line at a ticket counter.
* AI Tools: It uses Python tools (scikit-learn) to run the smart "brain" that detects fraud.

3.2 What the System Does (Functional Requirements)

3.2.1 F1: Receiving Money Info
The system must be able to verify and accept details about a money transfer, like "Who sent it?", "Who got it?", and "How much?".

3.2.2 F2: Basic Rule Checks
The system must check every transfer against a list of simple rules:
* Too Fast?: Did this person send money 10 times in 1 minute?
* Too Much?: Is the amount over $1,000,000?
* Banned List?: Is this person on a list of bad guys?

3.2.3 F3: AI "Weirdness" Detector
The system uses Artificial Intelligence to give every transfer a "Score" from 0 to 1.
* A score of 0 means "Totally Normal".
* A score of 1 means "Extremely Weird".
If the score is high, the system marks it as "Suspicious".

3.2.4 F4: Instant Updates
The dashboard screen must update instantly (in less than 5 seconds) when new data comes in. You shouldn't have to refresh the page.

3.2.5 F5: Warning System (Alerts)
When the system finds something wrong (either a broken rule or a high AI score), it must create an "Alert". The Admin can see these alerts and mark them as "Investigating" or "Solved".

3.3.1 Story #1: Checking a Suspicious Transfer
* Who does it: Admin
* Goal: To decide if a flagged transfer is real fraud or just a mistake.
* Priority: High (Do this first!)
* Steps:
    1. The Admin creates an account and logs in.
    2. The Dashboard shows a new "Suspicious" alert.
    3. The Admin clicks on it to see details (like "User sent $50,000 to a new account").
    4. The Admin investigates and decides "Yes, this is fraud" or "No, this is safe".
    5. The Admin clicks the "Mark as Fraud" button.
    6. The system saves this decision and closes the ticket.

3.3.2 Story #2: Getting the Data
* Who does it: External Banking System
* Goal: To send transaction details to Argus.
* Priority: Critical (Must work 100% of the time)
* Steps:
    1. The Bank's computer sends a message to Argus with transfer details.
    2. Argus checks if the message is written correctly.
    3. Argus saves the message to its database.
    4. Argus sends the message to the AI for checking.
    5. Argus replies to the Bank: "Got it, thanks!"
